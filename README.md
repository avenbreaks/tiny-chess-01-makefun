A compact chess engine in 4,096 bytes of Python: iterative-deepening alpha-beta search with quiescence, killer-move ordering, piece-square tables and an endgame mop-up evaluation, with full legal move generation (castling, en passant, promotion) on a 0x88 board. It plays the house gauntlet over HTTP, one move per request, fully deterministic.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
